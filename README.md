## 🚀 Featured Projects

<div align="center">

### 🔒 Driver Drowsiness & Distraction Detection
> *Private Repository*

Real-time dual-phase computer vision system for driver safety. Uses **MediaPipe Face Mesh** for EAR-based drowsiness detection + head pose estimation, and a custom-trained **YOLOv11** model for phone detection. Features auto-calibration, 8-frame smoothing, and CLAHE + gamma correction for low-light performance.

`Python` &nbsp; `MediaPipe` &nbsp; `YOLOv11` &nbsp; `OpenCV`

---

### 📈 [StockSense AI](https://github.com/vrajptl275/StockSense-AI)

AI-powered stock analysis chatbot with a **WhatsApp-style UI** and natural language query support for global stocks. Implements RSI, MACD, Bollinger Bands & SMA indicators with a hybrid **XGBoost + GARCH** model for buy/sell recommendations. Deployed live on Render.

`Flask` &nbsp; `XGBoost` &nbsp; `GARCH` &nbsp; `Plotly` &nbsp; `yfinance`

---

### 🏙️ [Anand Civic Issue Reporting System](https://github.com/vrajptl275/Anand-Civic-Issue-Reporting-System)

Full-stack civic platform with **4 role types** (Citizen, Officer, Dept Admin, Municipal Admin), GPS boundary validation, **Gemini AI** image analysis, JWT auth + bcrypt, and a 6-stage complaint lifecycle with Chart.js analytics. Deployed on Render.

`Flask` &nbsp; `PostgreSQL` &nbsp; `JWT` &nbsp; `Leaflet.js` &nbsp; `Gemini AI`

---

### 📋 [Smart Attendance System](https://github.com/vrajptl275/Smart-Attendance-System)

Web-based attendance platform using **face recognition** for real-time tracking. Features multi-role dashboards for Admin, Teacher & Student, CSV/PDF export, and production deployment with Gunicorn on Render.

`Flask` &nbsp; `Face Recognition` &nbsp; `SQLite` &nbsp; `Python`
